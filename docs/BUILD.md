# Build Guide

The build documentation is divided into three focused guides:

1. [Hardware assembly](HARDWARE_BUILD.md)
2. [Offline database generation](DATA_BUILD.md)
3. [Firmware configuration, compilation, and upload](FIRMWARE_BUILD.md)

Complete them in that order. The [Bill of Materials](BOM.md) lists the tested
required hardware, and the [User Guide](USER_GUIDE.md) covers first startup and
normal operation.
